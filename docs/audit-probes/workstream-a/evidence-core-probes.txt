Finding boundaries
------------------

F01 is reproduced end to end for a pinned callback target: changing the
callback target and factory body together produces no CAN6017 warning because
both expectations canonicalize through `unknown-kind(fnref)`. The other three
equalities demonstrate omissions in canonical structure: type arguments on Ok,
type arguments on patterns, and the invocation argument. They are evidence of
incomplete identity inputs, not by themselves a proof-cache exploit.

F02 is reproduced end to end: the compiler emits no diagnostic for two record
declarations with the same global name and incompatible fields. The selected
shape changes from `int` to `str` when the content assigned to the first sorted
filename changes. Current record identity is therefore global-short-name plus
first-wins input order, not declaration ownership.
