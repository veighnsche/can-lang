# Aliased document consistency

All three fresh consultations selected explicit conflict status (probabilities .97, .99, .98). Full request wording was audited before submission. This agreement is advice, not proof or guaranteed bias removal.

Selected after independent source reasoning: retain every URI buffer; restore the canonical overlay deterministically when one closes; share facts only for equal contents and retain every URI/version in freshness identity. Divergent aliases have no single correct project interpretation, so clear old findings and display an actionable conflict status instead of choosing a buffer silently. Source-changing operations require unambiguous document identity and explicitly decline duplicate aliases. Bounded regression tests verify restoration, identity, publication, conflict and edit refusal. Per-URI project forks add unnecessary semantic ownership and cache complexity; newest-event authority would infer the user's intent from scheduling.
