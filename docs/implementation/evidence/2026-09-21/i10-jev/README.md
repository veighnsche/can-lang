# I10 completion-carrier consultations

Three fresh requests compared fulfilled boxes for all completion categories with
exception-based failure control and unboxed async data. All explanatory context,
questions and option descriptions were rewritten; pairwise wording checks ran
before submission. The same contracts, existing interfaces, implementation
obligations and absence of performance evidence were preserved and checked for
semantic equivalence. Raw requests and responses are retained here.

All three `jev-1.13.0` responses chose `boxes`, with confidence 0.78, 0.81 and
0.95. No choice disagreement occurred. Exception transport remains an alternative
requiring careful catch boundaries; category boxes make the generated return and
native-settlement distinction explicit. Agreement is advice, not correctness
proof or guaranteed removal of wording bias. Source/checker/emitter tests and
native execution independently exercise the selected design.
