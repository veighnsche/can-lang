# I17 phase representation consultations

Three fresh SystemOne requests compare explicit checked phase IR, desugaring the
complete judge into ordinary regions, and runtime orchestration over generated
closures. Every context, instruction and option description was rewritten before
submission, preserving the same facts, constraints and alternatives. The saved
wording audit records that check. Requests and full raw responses are retained.

All three select explicit phase IR. Reported choice probabilities are 1.00, 0.87
and 0.84; confidence values are 1.00, 0.81 and 0.76. There is no selected-option
disagreement. The latter two also give synthetic regions 0.08 and 0.15, so the
advice does not establish that the alternative is invalid.

Implementation retains typed descriptor computations, ordered registrations,
state schemas and ordinary handler regions. Generated code will own the phase
sequencing; maintained runtime code owns protocol validation and transport.
Ordinary RegionEmitter operations remain reusable within phase emission. These
consultations are design advice, not proof of correctness or guaranteed bias
removal. Runtime/compiled integration evidence must establish actual behavior.
