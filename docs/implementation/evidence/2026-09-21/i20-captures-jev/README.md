# I20 ordinary callable capture policy

Three fresh requests rewrite every explanatory field while preserving the
ordinary-call self-close counterexample, P6/Q10 rules and the same alternatives.
All requests and raw responses are saved alongside this file.

All three select metadata on ordinary callables with leases at coordination and
native-operation boundaries and lifetime guards on maintained callbacks.
Confidence values are 0.83, 1.0 and 0.75. There is no categorical disagreement;
validation-only ordinary invocation receives some residual probability.

The implementation follows the contract's stated lease boundaries. A regression
shows an ordinary callable closing its captured resource without acquiring a
self-deadlocking wrapper lease. A checked/emitted callable fixture then proves
that launching that same kind of capture as a participant acquires and retains
its lease. Host callback wrapping preserves nested capture metadata. These tests,
not classifier agreement, support the choice; no bias-removal guarantee is made.
