# I20 lifecycle consultation

Three fresh requests preserve the same facts, constraints and alternatives,
with rewritten context, instructions, questions and option prose. Exact technical
identifiers remain unchanged. Requests and raw responses are stored here.

All three select retention until settlement over early release/cancellation.
For execution context, responses select AsyncLocalStorage, explicit context,
then AsyncLocalStorage. The second response is close (0.52 explicit versus 0.47
native context, confidence 0.29); this is a real disagreement, not consensus.

Investigation used the pinned native runtime: interleaved async-context
qualification, cross-root rejection, nested scope and participant tests, and a
native callback invoked outside an inherited context. Native AsyncLocalStorage
plus explicit binding at maintained callback entry preserves these cases without
adding a hidden argument to every generated function. The target qualification
now requires that native API and behavior. Agreement is advice, not proof or a
guarantee that rewording removed bias; the deterministic tests establish the
implemented contract.
