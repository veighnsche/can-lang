Implementation is authorized. Checkboxes record completed, verified tasks; unchecked tasks remain pending. IDs are stable; dependencies are task IDs, not chronological numbering. New paths below are proposed implementation locations. Existing files are to be replaced/adapted, not treated as policy. [Plan](plan.md) defines output/distribution invariants; [coverage](coverage.md) defines completeness.

Every task includes positive (P+), negative (N−), and integration (INT) evidence. “Done” requires the observable result and its tests, not only changed source.
