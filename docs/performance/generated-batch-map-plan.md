The actual `count_one` callback is a closed map<str,int>,str → map<str,int>

## B1 — closed transition proof

Create a proof separate from `MapLeafProof`, tied to the exact concrete checked
ProgramFunction identity, final resolved binding, source, full IR, collection
specialization and factory method identities. No benchmark name, source spelling,
emitted-text scan or public flag can admit the path. The positive class has
exactly `(map<K,int>, K) → map<K,int>` for K int/bool/str, no captures/resources,
Escapes, emitted errors, body statements, coordination or user calls. Restrict
the terminal to the **complete** get→absent-insert / present-replace tree:

- The get receives the original map and input key. Its absent arm calls insert
  on that map/key with a pure int expression, then returns precisely the new map
  binding. Its present arm binds the old int, calls replace on the same map/key
  with a pure int expression, then returns precisely the new map binding.
- Only the canonical checked get/insert/replace Entry-selected map specialization,
  contracts, errors, exact resolved receiver.method targets and positional pure
  prepared arguments qualify. The existing leaf proof can be a prerequisite but
  is not sufficient. Verify every arm: only the matching canonical domain arm
  may return the original map, and its condition must be impossible for the
  guarded private Map state. Reject standard/forward arms, alternate success
  payloads, arbitrary matching, recursive/indirect/special/native calls, fields,
  division/remainder/power, mutable resources and any other IR node.
- Pure int expressions are literals, scoped int inputs/old-value bindings,
  unary minus and binary +,-,* with exact types/arity/operators; evaluate each
  once in checked source order. A str/bool key cannot be used as int. Require
  complete scope and binding equality. If the real gallery IR conflicts, do not
  weaken proof to make it pass: release affected writers and report the exact
  node/contract for Codex review.

The runtime fold site is the sole consumer. It must already have its exact
private callable metadata, no assertion context or owner, a real ordinary
nonproxy frozen dense Array.prototype input with own primitive data slots of
the proven key kind, and a privately branded initial map of the exact identity
whose existing values are bigint. Check all guards **before the first visit**.
An empty input returns the original initial map token without constructing a
replacement. A failed guard invokes the original adapter from the beginning;
there is no replay after an effect.

## B2 — native ownership and execution

Use a private factory-owned batch capability authenticated by exact canonical
method-function identity, not callback names, public Can metadata or arbitrary
host properties. It may clone the initial private backing Map **once**, retain
that clone exclusively within the reduction, apply pure int transitions using
native `Map.has/get/set`, and publish through the existing `own()` boundary
**once**. The published result gets the same frozen token, private storage and
independent opaque-contents snapshot as an ordinary map update. Never mutate a
published token or backing Map, expose the builder or skip the final snapshot.
Preserve insertion order, key kind and bigint validation, old snapshots, resource
containment, and the normal seven-method frozen async map API. A host-created map
with non-bigint values, wrong factory identity, proxy or other hostile input
declines before traversal. No per-word token, Completion, Promise, snapshot or
origin object on the admitted successful path. The normal leaf and generic paths
remain unchanged.

The compiler emits only proof-qualified transition code and private descriptor
metadata, alongside the unchanged authored async function and leaf companion.
Reuse exact source/span mappings; no eager per-word origin construction. The
private descriptor validates own data/proxy status, arity, key kind and resolved
factory identity without getter/then access. At a cold injected failure, retain
the actual defining call-site first standard boundary, region, source span,
fresh occurrence and stop order; never assimilate a raw payload through Promise.
If those semantics cannot be maintained for a proven transition, decline it.
