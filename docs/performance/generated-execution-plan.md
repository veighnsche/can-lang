property descriptor table and two descriptors, then freezes the object and admits
it in a private WeakSet. A native null-prototype literal followed by freeze removes
the descriptor scaffolding. Its final enumerable `kind`/`value` data keys, readonly
and nonconfigurable attributes, fresh frozen identity and exact payload reference
can remain equivalent. The literal's `__proto__: null` sets the prototype; it must
not introduce a third own property. Preserve WeakSet branding and membership before
any carrier property inspection. Do not inspect payload getters/then, change

`runtime/collections/map.ts` owns an inaccessible native Map and publishes opaque
containment by `Array.from(values.values())`. `runtime/data.ts` immediately spreads
that array into a second frozen private snapshot. Change registration input to
`Iterable<unknown>` and pass the backing Map's values iterator directly. Registration
still owns one copied, frozen ordered snapshot and rejects a second registration
before touching the iterable. Existing array clients retain defensive copying;
failed iteration must not register partial metadata. Preserve every native Map
copy for immutable updates and exact value references. Construction records
containment but acquires no lease; owner participant preparation, rollback and
closing remain unchanged. This remedy applies to maps, not primitive-only sets.
