# Pre-dispatch audit

Three fresh requests were prepared for this behavior-design pass. Every context, question and option description was rewritten, not just an instruction prefix. Mechanical checks confirm distinct full text at each explanatory field, identical question IDs and identical alternatives. Model/type/option identifiers intentionally remain stable.

Manual semantic comparison: all packets preserve the same seven raw errors and fields, origin collision, body/envelope distinction, judge order, baseline identity, single-base/no-retry candidate, finite bound calculation, nominal generic error discrimination, snapshot/catch ownership, current driver behavior, whole-graph publication candidate, 5000ms per-root default and 1..600000ms range, fixture identities and FIFO checks, raw-versus-supplied evidence and override testing. The nine questions compare the same alternatives in each packet. “Optional alias” and “as binder” refer to the same proposed exact pattern binder; neither requires aliases everywhere.

The classifier has no source access. Context supplies the relevant implementation/spec evidence, constraints and tradeoffs. These are alternative contract choices, not requests to research or validate a compiler. Results are advisory. The coordinator will inspect any disagreement and retain independent responsibility for the selected rules and unproven implementation claims.
