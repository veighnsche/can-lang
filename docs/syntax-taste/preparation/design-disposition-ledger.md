# Planned design dispositions across the recommendation program

24 September 2026. This is the P8 integration ledger for the planned design, not current
compiler behavior. An **accept** entry
means the planned design includes the stated contract; **retain** preserves a
current contract while allowing its tests or documentation to improve;
**defer** leaves a mechanism outside the first implementation plan with an
explicit reopening condition. Source evidence and concrete acceptance cases
remain in the linked topic packets. The user froze an AI-agent audience and
made total tokens per successful agent task a secondary measured objective.
Later instruction: ask no further design questions; consult Jev and record
engineering judgment. The earlier `bind` and qualified-import choices stand.
