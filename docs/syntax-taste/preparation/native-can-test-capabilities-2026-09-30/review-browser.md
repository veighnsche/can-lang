# Browser contract review

Read-only design review of [the main capability contract](../../native-can-test-capabilities-2026-09-30.md#L104) against the current browser scripts. No implementation or runtime qualification was performed.

1. **Independent DOM event snapshots need an explicit subscription contract.** `browser.watch` names request/response/failure, console/page-error and *custom* events, while `browser.dom_action` records only what the driver dispatched. The static native-control oracle installs listeners and reads the event fields actually delivered to the page: key, modifiers, `isComposing`, and input data ([controls-native.mjs](../../../../tests/integration/browser/controls-native.mjs#L145), [controls-native.mjs](../../../../tests/integration/browser/controls-native.mjs#L218)). Can-emitted controls echo some of these, but that echo is the candidate adapter's projection ([controls.mjs](../../../../tests/integration/browser/controls.mjs#L141)). Add a generic, target-scoped `watch_dom_event` or a clearly defined `browser.watch` variant that arms before an action and returns immutable browser-observed event snapshots with `type`, `key`, modifiers, `isComposing`, `data`, bubbles/cancelable, `isTrusted`, target identity and sequence. It must not install a case-specific callback or decide expected values. This closes a real ledger obligation, not merely a convenience gap ([BROWSER-043](../native-can-tests-migration-ledger-2026-09-30/browser.md#L1116)).

2. **Tie actions to event windows without claiming a false total order.** The generic event envelope rightly gives per-channel sequence and warns against inferring cross-process causality from arrival order ([main contract](../../native-can-test-capabilities-2026-09-30.md#L45)). Browser input/navigation results and browser event records also need a defined *same-driver* fence: arm a cursor before the action; return action ID, navigation/document generation and a driver event watermark or explicitly state that the action acknowledgment is not an event-completion fence. A Can case can then wait for an event/DOM predicate, compare the cursor delta, and finally seal. Otherwise an agent may count requests immediately after `browser.input` and miss a queued `request` or late page error. This matters for exact one-POST and after-disposal silence in [grid.mjs](../../../../tests/integration/browser/grid.mjs#L382) and [grid.mjs](../../../../tests/integration/browser/grid.mjs#L679). Do not infer that all browser requests are caused by the most recent click; timer/poll traffic has no such causal identity.

3. **Specify the fetched-route terminal transition and acknowledgment recovery.** The split `browser.route_fetch` → `browser.route_resolve` correctly avoids retrying upstream after a committed write ([main contract](../../native-can-test-capabilities-2026-09-30.md#L121), [grid.mjs](../../../../tests/integration/browser/grid.mjs#L555)). The table should name the post-fetch legal decisions precisely: `fulfill_fetched`/`fulfill_bytes` (possibly altered), or abort; `continue-original` must reject. A lost `route_fetch` or `route_resolve` acknowledgment must rejoin/query the same token/operation and return its known contact/delivery state, never dispatch another fetch or synthetic fulfill. Define what happens if upstream body capture exceeds its bound: no claimed exact pass-through/corruption evidence. `route_fetch` should retain the upstream response identity and contact count separately from the browser-delivered response identity. The main generic at-most-once rule already points this way ([main contract](../../native-can-test-capabilities-2026-09-30.md#L33)); the browser-specific state machine should make it mechanical for authors.

4. **Keep `checkpoint` and terminal `seal` as separate named operations in the table.** The prose correctly states that a quiet period or DOM predicate is only a prefix checkpoint and that final seal stops/closes context activity and drains callbacks ([main contract](../../native-can-test-capabilities-2026-09-30.md#L135)). The table still lists `browser.seal` with “terminal close **or bounded observation boundary**” ([main contract](../../native-can-test-capabilities-2026-09-30.md#L125)). For reliable agent-authored absence assertions, expose `browser.checkpoint(cursor, boundary)` returning a *prefix* watermark and `browser.seal(cursor, close)` returning a terminal receipt with pending callbacks/routes/body captures and gaps. A prefix observation may prove a bounded interval or a positive witness; it cannot prove no later event. The current scripts deliberately inspect errors after disposal/navigation ([grid.mjs](../../../../tests/integration/browser/grid.mjs#L679)).

5. **Qualify the scope of “before contact” on routes.** `browser.route` says a paused token arrives before contact, while the later policy paragraph correctly requires a separately qualified boundary for redirects, preconnect, service workers, WebSockets and remote Firefox egress ([main contract](../../native-can-test-capabilities-2026-09-30.md#L121), [main contract](../../native-can-test-capabilities-2026-09-30.md#L137)). State that a route token precedes only that routed request's *driver-managed upstream fetch*; it is not universal proof that the browser/remote host made no other contact. The existing scripts' Playwright loopback route and request ledger provide observed request evidence, not a host-enforced egress guarantee ([controls-native.mjs](../../../../tests/integration/browser/controls-native.mjs#L40), [firefox-remote.mjs](../../../../tests/integration/browser/firefox-remote.mjs#L1)). This avoids a misleading API promise while preserving the stronger admission gate.

The contract already makes strong agent-oriented choices: selectors require explicit cardinality, physical and synthetic actions are distinct, request/response bodies are immutable and completion-aware, `route_fetch` is separate from delivery, browser ownership survives worker death, and the main prose rejects quiet-time final seals. Canonical Can package signatures and two small boundary-fixture-backed examples remain deferred explicitly by the document; add them before freezing implementation lanes so generated scenarios do not guess error variants or event-cursor semantics ([main contract](../../native-can-test-capabilities-2026-09-30.md#L19), [main contract](../../native-can-test-capabilities-2026-09-30.md#L252)).
