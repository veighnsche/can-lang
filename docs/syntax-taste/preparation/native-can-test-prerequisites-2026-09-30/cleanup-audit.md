## Missing before bounded probes

The experiment register makes exact R/C/native artifacts, a minimal nonpublishing fixture path, external owner and supported host guarantees prerequisites to **every** entry; all entries remain unrun ([experiments.md, lines 1–15](../native-can-test-hard-cases-2026-09-30/experiments.md#L1)). The lifecycle requires externally confirmed descendant/descriptor release, an outside reservation ledger before allocation, recovery before new admission, and matching cleanup receipts ([lifecycle, lines 164–216](../../native-can-test-lifecycle-2026-09-30.md#L164)). The capability contract itself calls host enforcement an implementation gate and says process groups do not contain detached descendants ([capabilities, lines 55–61](../../native-can-test-capabilities-2026-09-30.md#L55)). **No executable N meeting these contracts is established in the audited sources.**

The smallest justifiable owner selection is a **new, trusted, generic Go owner outside all Can worker/C processes**, reusing reviewed distribution/descriptor/lease mechanisms and safe owned-scratch ideas. Give it its own pinned identity and capability/host guarantee record. It must register scopes before effects, reserve a bounded process/scratch/descriptor envelope, launch and observe children under a demonstrated host containment policy, survive subordinate worker/launcher death, return raw execution/cleanup facts, and recover only its own abandoned scopes. It must not choose scenarios, expectations or reports. On this Mac, claiming full descendant containment, strict disk quota or hostile-input immutability requires a demonstrated mechanism; until then, affected variants are blocked rather than credited. The Python performance owner is source precedent for group and scratch mechanics, not the selected N implementation.
