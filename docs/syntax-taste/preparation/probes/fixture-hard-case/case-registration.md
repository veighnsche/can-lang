# DI-06 private-effect fixture comparison: preregistration

24 September 2026. Source revision `02a549d28fd5fc5c3996160e65a97de332390d30`. This is a hand-authored mechanism comparison using the present compiler, not a language feature or agent-token benchmark. A library's public `stamp(int)` function reads `clock::wall_millis()` inside a private `sample_time()` function, converts the resulting integer, and appends `"!"`. Two ordinary consumer functions call `stamp`; a caller assertion expects the controlled `"1000!"` result. The clock dependency is deliberately private to the library's behavior and absent from its functional input contract.

Before running, compare these forms:

1. **Ambient helper row:** `sample_time()` has a foreign `customer` lexical `when` row supplying 1000. Expect the caller assertion named `customer` to pass and a caller-only rename to `renamed` to fail, while checking still succeeds.
2. **Whole-helper stub:** the caller supplies the complete `helper::stamp(7)` result locally. Expect both caller labels to pass when the local selector is renamed with the assertion. Changing the helper body should remain invisible on the caller path; report `supplied-completion`.
3. **Public-parameter injection:** `stamp` accepts a typed `now` callable, with a helper-owned real-clock wrapper passed by both normal call sites and a caller-authored fake passed by the assertion. Expect the caller result to survive label rename and depend on both fake clock and helper suffix. Count public signature inputs, newly exported declarations, changed files and edited call sites.
4. **Separate exported test entry:** preserve production `stamp(int)` but export `stamp_with_clock(int, callable)`; the production entry and test entry share the same core helper body. Expect the test entry to exercise that body, while adding a public test-facing function and exposing the private time dependency in that function's type. Count contract and call-site edits.

For cases 3–4, change only the fake clock result and only the helper's suffix in separate copies. Expect each assertion to fail with `real-can`, establishing caller-through-helper body coverage. In case 2, change only the helper suffix and expect the assertion still to pass. In case 1, repair the helper selector to `renamed` and record the cross-package second-file edit. All cases should compile and execute all attached roots; record exact checker and runtime reports.
